# Reel Monster — Build Prompts

## Prompt 1 — Plan
Build a browser-based adaptation of Reel Monster, Project 6, Level 1 (manual). Preserve the brief's manual counter, cute monster, growing reactions, today's count, estimated time lost, last-seven-days history, offline use, and no-login requirement. Do not claim to provide an Android overlay.

## Prompt 2 — Build
Create a responsive static HTML, CSS, and vanilla JavaScript app. It must run by opening index.html directly, use localStorage for persistent daily counts, have a +1 button, show monster reactions based on count, display today's count/time estimate/7-day chart, and export history to CSV. Do not use a backend, external API, or build tools.

## Prompt 3 — Review
Check the code for missing elements, responsive layout, safe localStorage parsing, date-based daily totals, and CSV export. Document the difference between this browser adaptation and the Android-only requirement in the source brief.
