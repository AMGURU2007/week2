# Resume Builder (Project 3)

Offline, single-file HTML/CSS/JavaScript resume builder.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Edit your details and entries; the A4 preview updates automatically.
4. Choose Modern, Classic, or Minimal.
5. Drag section chips to reorder sections.
6. Use **Save data** to export JSON, and **Load data** to restore it.
7. Use **Export PDF** and choose **Save as PDF** in the browser print dialog.

No server, login, external library, or internet connection is required.
